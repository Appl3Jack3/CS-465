Architecture- Frontend Comparison: Express HTML, JavaScript, and SPA
Throughout this project, I worked with two different front-end approaches:
- the customer-facing Express HTML pages and JavaScript, working well for simple, server-rendered pages
- the administrative single-page application (SPA), allowing faster updates, reusable components, and smoother user experience
The backend used MongoDB because its NoSQL structures store flexible, JSON- like documents, making it easy to adjust data models as the project evolved.

Functionality:
JSON is a lightweight data format, while JavaScript is a programming language. JSON connects the frontend and backend by sending structures data through API 
requests and responses. Throughout the project, I refactored repeated code into shared functions and reused UI components in the SPA to improve consistency,
reduce the duplication and make updates easier.

Testing:
Testing required checking each API method
- GET
- POST
